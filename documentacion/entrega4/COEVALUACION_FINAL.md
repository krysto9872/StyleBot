## Reglas para aplicar penalizaciones

1. Las penalizaciones se aplican solamente después de vencer el plazo correspondiente.
2. Se utilizará la fecha y hora del commit como evidencia principal.
3. Un bloqueo avisado con anticipación puede justificar una prórroga autorizada por el líder.
4. Ayudar a otro integrante no elimina la responsabilidad del encargado original.
5. Si otra persona debe terminar una tarea abandonada, se registrará quién produjo realmente el entregable.
6. No se descontarán puntos dos veces por el mismo incumplimiento.
7. Toda calificación debe incluir una explicación breve y verificable.
