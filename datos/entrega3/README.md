# Datos de la Entrega 3

Esta carpeta guarda únicamente archivos pequeños y reproducibles usados para evaluar el agente.

- `protocolo_entrega3.json`: constantes comunes del almacén, acciones, recompensas y semillas.
- Los índices de las 50 prendas de demostración deberán guardarse aquí cuando se genere la corrida final.
- No se deben subir copias completas de Fashion-MNIST porque el dataset se descarga desde TensorFlow.
- El conjunto de prueba no se usa para entrenar ni seleccionar hiperparámetros.
