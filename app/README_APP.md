# Aplicación web opcional de StyleBot

La aplicación con Streamlit es una actividad adicional para obtener puntos extra. No genera imágenes: clasifica una prenda y muestra la decisión del agente.

Funciones previstas:

1. Seleccionar una muestra de Fashion-MNIST o cargar una imagen.
2. Convertirla a 28 por 28 píxeles en escala de grises.
3. Mostrar categoría y confianza.
4. Mostrar estante objetivo.
5. Elegir Q-Learning o Dyna-Q.
6. Mostrar recorrido, pasos, recompensa y resultado.

Archivo esperado: app.py.
